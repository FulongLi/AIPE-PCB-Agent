Reusable additions are generic closed-loop geometry, actual-polygon connectivity and projected return checks, a multilayer DC resistor mesh, a real-copper path witness, assembly-envelope distance/contact screening, exact pad escape clearance and safe native dangling-junction normalization. They accept geometry/net/path inputs; V3 dimensions live in the V3 orchestration modules. Regression tests exercise holes, absent vertical connections, rectangle sheet resistance, preserved junctions and intentional/unexplained envelope contacts.
