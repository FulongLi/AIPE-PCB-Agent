# Reproduce V3 evidence

Use the committed final native projects as the review inputs. This procedure does not reroute historical boards or replace the final V3 placement. The original design-generation milestones remain in Git for development history. Rerouting is not required to reproduce the delivered checks.

Environment actually used: Windows, KiCad 10.0.7 / pcbnew Python 3.11, host Python 3.10 with NumPy/SciPy/Shapely/Pillow/PyMuPDF, and the existing ngspice 46 DLL runner. No new software was installed. On this machine:

```powershell
$hostPython = 'C:\Users\Zhongnan Qian\AppData\Local\Programs\Python\Python310\python.exe'
$cadPython = 'D:\EngineeringTools\KiCad\10.0\bin\python.exe'
$cadCli = 'D:\EngineeringTools\KiCad\10.0\bin\kicad-cli.exe'
```

Run from the repository root. Adapt these executable paths on another machine; retain the recorded versions for comparison. Do not install missing software without confirming the software and destination with the user.

```powershell
& $hostPython -X utf8 -m automation.sic_v3.calculations
& $hostPython -X utf8 -m automation.sic_v3.simulation --stage all
& $cadPython -X utf8 -m automation.sic_v3.verify_copper export
& $hostPython -X utf8 -m automation.sic_v3.verify_copper review
& $hostPython -X utf8 -m automation.sic_v3.verify_copper mesh
& $hostPython -X utf8 -m automation.sic_v3.final_loops
& $cadPython -X utf8 -m automation.sic_v3.verify_package netlists
& $hostPython -X utf8 -m automation.sic_v3.verify_package evidence
```

Copper export is transient under ignored `.aipe/v3/`; durable derived evidence is in the V3 example. The mesh uses two grid spacings per endpoint case and can take several minutes. Final-loop paths are geometrical witnesses; no field solver or hardware measurement is implied. Numerical source hashes are in simulation provenance. Native run paths in historical logs identify the original workstation; portable V3 orchestrators locate repository inputs relative to the checkout.

For a fresh native check, run `automation.kicad_tools.run_check erc <root schematic> --output <new evidence directory>` for power, control and system. Check delivered stored board fills with:

```powershell
& $cadCli pcb drc --format json --all-track-errors --schematic-parity --severity-all --exit-code-violations -o .aipe/v3/recheck-power.json examples/sic-buck-400v-200v-5kw-v3/kicad/power_board/sic-v3-power.kicad_pcb
& $cadCli pcb drc --format json --all-track-errors --schematic-parity --severity-all --exit-code-violations -o .aipe/v3/recheck-control.json examples/sic-buck-400v-200v-5kw-v3/kicad/control_board/sic-v3-control.kicad_pcb
```

The final completion manifests bind each board to its native report. Historical intermediate ERC/placement reports may contain findings; the latest current-input runs used for the final gates are explicitly selected in `verification/final_validation.json`. Do not treat an old clean root-sheet hash as evidence for changed child sheets or libraries.

Regenerate manufacturing outputs into **new empty directories** with `automation.kicad_tools.export_outputs <project basename> --output <fresh path> --layers F.Cu,In1.Cu,In2.Cu,B.Cu,F.SilkS,B.SilkS,Edge.Cuts --assembly-step --pdf-scale 1.05` for power, using `--pdf-scale 1.6` for control. The V3 render stage uses 0.88 zoom to leave room for tall film bodies. Assembly PDFs use native `pcb export pdf --mode-multipage --layers F.Fab,B.Fab --common-layers Edge.Cuts --include-border-title --black-and-white` with the same board-specific scales. System PDF uses native `sch export pdf`.

`automation.sic_v3.review_package render`, `prepare` and `freeze` respectively refresh final isometric images/export hashes, copy/render review documents and hash the package. Rendering and text bounds do not replace visual inspection. Any changed PDF/PNG requires a fresh visual review record before `verify_package evidence` can pass. `review/package_manifest.json` excludes itself to avoid circular hashing. Final human engineering sign-off is never generated by these commands.

The full regression command was `python -m unittest discover -s tests -v` (373 tests, two skipped). Knowledge validation was `python -m automation.knowledge.validate` (pass, with 19 older component cache checks skipped). Some legacy tests regenerate two V2 netlist timestamps in the working tree; inspect those diffs and restore only that test-generated timestamp drift before committing. Never regenerate or overwrite the frozen V1/V2 design history to run the V3 review.
