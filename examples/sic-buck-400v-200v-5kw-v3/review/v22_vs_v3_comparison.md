# V2.2 versus V3: measured changes and limits

V2.2 is read from baseline `20e96fdfa5ea76649daa416ee70b7ea7798a319d`; its frozen history is unchanged. V3 is an independent circuit/floorplan. Native inventory is in `verification/engineering_checks/board_inventory.json`; copper, model and assembly evidence is linked below. This is not a claim of superior measured hardware performance.

| Topic | V2.2 | V3 | Evidence / tradeoff |
|---|---|---|---|
| 1. System architecture | Four-layer power/control pair with stacked 2×25 mezzanine and partially supported control overhang | Independently supported boards; keyed 40-way cable; chassis magnetics/sensor/contactors | Architecture comparison and assembly model. Improves explicit support/load partition; introduces a longer 160 mm signal cable |
| 2. | 3. | 4. | 10. | 13. | 16. Remaining issues | 18 E22 issues, several needing hardware or major layout change | All 18 receive explicit root-cause response, geometry/analysis and residual-risk disposition; 20 release holds remain | No experimental closure. Fuse/source/SiC survival, insulation, thermal fixture, copper, capacitors, target timing and EMC still block release |

Native final footprint counts are 202 power /266 control, versus 237/211 in V2.2: total 468 versus 448 (+20). The off-board choke is additionally represented in the schematic/model; it is not a power-PCB footprint. Total vias decrease from 606/805 to 329/761, but a via count reduction is not an electrical performance metric. V3 also retains irregular low-frequency branches and increases several aggregate gate/Kelvin network lengths. The report does not conceal those regressions.

The two V3 floorplan source boards and their original comparison are preserved in `pcb/floorplan_candidates/`. Final views are `pcb_power.png`, `pcb_control.png`, the 3D PNGs and PCB PDFs here. Compare them with the unchanged baseline CAD/plots through Git rather than duplicating large historical images. The local path JSON contains the coordinates needed to inspect actual layer changes and capacitor returns; its proxies are not imaginary nH values.
