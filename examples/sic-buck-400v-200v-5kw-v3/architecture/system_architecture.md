# V3 system design direction

400 V input → DC fuse → main contactor (parallel switched resistor precharge branch) → local film DC link → vertical SiC half bridge → chassis-mounted biased powder-core choke → aperture Hall current sensing → film output capacitance → 200 V output. Permanent discharge resistors on link and output provide a passive discharge path when auxiliary power is lost. PE bonds the enclosure and isolated heatsink, not the hazardous power return.

The half bridge uses a new compact placement centred on the **complete** HF capacitor–HS drain–HS source–LS drain–LS source–capacitor return path. Driver positions derive from the MOSFET gate and Kelvin pins. Gate and return traces form a paired path without joining Kelvin source to the main power return on the PCB. Bias feedback uses its own VEEA quiet network with a single physical star to the bias power VEE; high gate-charge currents cannot traverse that branch.

Selected semiconductor: Wolfspeed C4MS025120K, compared with C3M0030090K. The 1200 V part provides 400 V margin over the provisional 800 V switching-peak target, versus only100 V for the900 V candidate. The four-lead package has an independent Kelvin source. Gate bias is nominal +17.17/-4.01 V:121k/16.2k total-output feedback and9.76k/16.2k negative feedback. Including the bias IC's independent +/-1.3% regulation limits and0.1% resistors keeps the static positive rail below18 V; dynamic ripple is still a measurement item. Loss calculations apply an explicitly unverified10% increment over the temperature-scaled18 V RDS(on) data, because the18 V maximum is not a guaranteed bound at17.17 V. UCC21710-Q1 and UCC14141-Q1 are retained with new feedback and capacitor networks. TI's DW0016B **HV land-pattern option**,9.75 mm row centres and1.65 mm pad length, provides8.10 mm nominal clearance; the old7.3 mm nominal footprint is unsuitable for this design basis. UCC14141's retrieved June2023 datasheet lists certifications as planned; current certification confirmation remains open.

Voltage measurement includes raw input, DC link and output, permitting precharge progress and welded-contact checks. A separate isolated sensing supply avoids loading a gate-driver Kelvin return. Current measurement uses the LEM HO 50-S-0100 aperture sensor, removing the 25 A PCB sensor-pad neck and allowing bipolar measurement. Its full March 2022 v7 datasheet, not the broader marketing bandwidth, controls the design (100 kHz small-signal bandwidth for this variant). Sensor reference loading and connector pinout will be verified in the detailed model.

Protection includes bipolar current window, output overvoltage, input undervoltage, driver FLT/RDY and bias PG supervision, temperature and fan monitoring. A latched asynchronous inhibit reaches driver enables and DSP trip zone. F28335 ePWM dead-band generates actual non-overlap; input cross-interlock alone is not dead time. Startup state machine verifies auxiliary rails, current zero, input range, discharge/precharge progress and contactor feedback before enabling a 200 ms reference ramp. Fault reset requires gates off and a deliberate reset sequence.

No completed electrical, simulation, CAD or hardware verification is claimed by this architecture document. Detailed selections, calculated ratings, actual connections and all gates follow in later milestones.
