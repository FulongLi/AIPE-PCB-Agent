# F28335 reproducible control implementation specification

This is an implementation specification with an executed Python control algorithm, **not compiled target firmware**. No TI compiler or target board was available. The actual part/pin assignment is in `design/circuit_control.json`; the executable numerical reference is `automation/sic_v3/simulation.py`. Target build, register audit, ADC calibration and oscilloscope timing tests are mandatory before energising hardware.

## PWM, sampling and control

Use a verified 30 MHz external clock and the F28335 PLL configuration for 150 MHz SYSCLK. Configure ePWM1 GPIO0/1 in up/down mode, TBCLK=150 MHz, TBPRD=1500: 50 kHz. Use the hardware dead-band module with DBRED=DBFED=45 TBCLK counts for nominal 300 ns; active-high complementary outputs. Load compare values from shadow at the specified cycle boundary. The separate combinational interlock is additional protection, not the source of deadtime. Verify both turn-on edges, propagation skew, minimum on/off time and all trip/restart transitions on a low-voltage fixture.

ADC acquisition is triggered at the stable centre of the high-side pulse once each 20 µs period. Match the model's measured-sample to applied-command delay of one whole cycle. Sequence BUS, CURRENT, RAW, OUT, TEMP, IREF and V12; measure conversion completion and ISR deadline. Keep the ADC clock within the manufacturer's limit and begin with a long acquisition window (e.g. ACQ_PS=15), then confirm settling of the 220 Ω/1 nF front ends. Measure actual sampling phase against switching edges; do not infer it from ISR time. The model uses 3.74 µs current and 12 µs voltage/bus aggregate lags as assumptions.

For 12-bit counts `q`, `Vad = q * 3.0 / 4096` before calibration. Current is `(Vad - 1.5)/0.032`; RAW/BUS voltage is `Vad*301/1.5`; output is `Vad*151/1.5`. IREF is the buffered sensor reference directly and must be within 2.4–2.6 V before arming. Apply per-channel offset/gain calibration and plausibility checks; validate signs with known currents. Overrange, stale samples and impossible cross-channel relationships are latched faults.

At each sample, compute the outer voltage PI (`Kp=0.65 A/V`, `Ki=400 A/V/s`) and clamp its current reference to 0–32 A. Compute the inner current PI (`Kp=0.015 duty/A`, `Ki=3.5 duty/A/s`), add measured-output/measured-bus feedforward and 0.015 deadtime compensation, then clamp duty to 0–0.94 and round to 1/1500. Both integrators use the conditional-integration anti-windup in the executed reference. A duty of zero means both gates inhibited, not continuous synchronous low-side conduction. The reference ramps 0→200 V in 200 ms. Initial integrator states and reset on trip must match the reference model. Negative sustained current or externally powered output is outside the approved operating envelope.

## Hardware fault path and state machine

GPIO12 is asynchronous TZ1 from ARMED; GPIO13 is asynchronous TZ2 from CURRENT_OK. Configure active-low one-shot trips and force both PWM outputs low. The board fault latch asynchronously clears on any relevant inhibit; software cannot override it. Gate-driver DESAT acts locally without waiting for the DSP. On every reset, PWM pin mux remains GPIO-low, RUN_ENABLE/ARM_PULSE/BIAS_EN/MAIN_CMD/PRE_CMD are low and the hardware latch is clear.

1. **SAFE:** force PWM off; open both contactors; validate core/3.3 V rails, reset supervisor, firmware CRC, ADC reference, thermal/ESTOP loop and ADC plausibility. Confirm no externally energised output and both auxiliary contact feedbacks open.
2. **BIAS CHECK:** enable bias, reset drivers, wait for all bias/driver-ready signals within a bounded timeout. Keep PWM off. Verify fan tach with auxiliary supply present. PG signals are active low where named `_N`; use the actual model truth table, not guessed polarity.
3. **PRECHARGE:** close only PRE. Require feedback confirmation, raw input 360–440 V, monotonically rising bus and timeout ≤1 s. When RAW−BUS≤8 V for a debounced interval, close MAIN and verify its auxiliary contact. Open PRE and verify it opens. Never overlap transitions blindly; retain timestamped feedback faults.
4. **ARM / RAMP:** all hardware causes clear, sensor reference valid, zero-duty PWM configured with deadtime and TZ. Clear permitted TZ flags, issue one ARM edge, assert RUN_ENABLE and start the current-limited reference ramp. Check ISR execution time before each shadow update.
5. **RUN:** regulate at 200 V; allow 30 A for at most 1 s, otherwise current-limit/fault. Monitor fan tach, driver APWM board temperatures, heatsink/choke thermostat, sensor reference, driver PG/FLT/RDY, raw/bus/output voltage and contactor feedback. Missing fan tach trips; threshold and pulse-per-revolution conversion must follow the selected fan's confirmed sensor specification.
6. **STOP / FAULT:** immediately inhibit PWM; latch cause and reset integrators. Allow inductor current to decay while monitoring; then open MAIN. A catastrophic fault may require immediate contactor action, but its actual interruption capability must be qualified against source energy. PRE stays open. Bleeders work without firmware; show hazardous voltage until independent voltage checks confirm discharge. No automatic fault re-arm: require a deliberate command after the cause clears and the full SAFE sequence passes.

Watchdog, clock-loss, ADC/ISR deadline, RAM/flash integrity and brownout faults all enter SAFE. JTAG/UART are accessible only on the isolated control side, with the specified short cables. Target code must include a register dump and pin-state test proving boot/reset cannot create a gate pulse or energise a contactor. Firmware qualification requires a real compiler build plus timing and fault-injection evidence; the executed Python model alone does not satisfy that gate.
