# Lessons from the independent V3 engineering design

Evidence level: manufacturer guidance, analytical calculations, behavioral simulations and native CAD experiments. **No hardware validation.** The V3 example records each exact part, environment, input revision and remaining qualification. These lessons do not make its prototype production ready.

1. **Compare closed current paths before selecting a floorplan.** Include the forward conductor, return conductor, vertical transitions and explicit component-terminal bridges. Reject open or disconnected path inputs. `automation/kicad_tools/loop_geometry.py` does this without inventing an inductance. A projected area can cancel in a folded path; therefore report the ordered path, total external length and 3D vector-area components together. Semiconductor internal bridges and zone centerlines are proxies until package/field extraction or measurement is available. Applicable guidance: [Wolfspeed CGD15SG00D2](../references/wolfspeed/cgd15sg00d2/analysis.md), [CGD1700HB2M-UNA](../references/wolfspeed/cgd1700hb2m-una/analysis.md).

2. **Place against actual escape copper, not courtyard spacing alone.** A component-only DRC pass can be invalidated by a fine-pitch fanout: a through via may collide with a bypass land on the other side. V3 checks DSP escape geometry against front and back lands before routing. The generic `qfp_escape.py` plans relative to the actual package; `project_board.place_in_region(..., copper_gap=...)` screens pad-to-copper placement. Its segment bounding boxes are conservative and native DRC remains authoritative. Empty-number stencil apertures must be excluded when classifying pin rows. No fixed clearance value is universal.

3. **A separate VEEA net requires a separate physical return branch.** [TI UCC14141-Q1](https://www.ti.com/lit/ds/symlink/ucc14141-q1.pdf) specifies the feedback return arrangement. Place the quiet tie before bulk power copper; connect the divider bottoms and filter capacitors to pin 35, with one intended connection at the specified VEE return. Inspect all-layer fills and actual connected components. A net tie must not become a second path under a load-return pour. Measure regulation and noise after the copper topology passes.

4. **Treat broad planar isolation and same-layer clearance as distinct checks.** Manufacturer package certification and a CAD net-class matrix do not establish board/chassis insulation. A same-layer clearance check can miss hazardous copper below accessible control copper. The reusable pairwise router projects designated barrier exclusions across all routing layers and retains potential-dependent functional spacing elsewhere. Verify the final filled copper independently and include slots, screws, enclosure, material group, pollution, altitude, impulse source and tolerances. [TI TIDA-010054](../references/ti/tida-010054/analysis.md) is a reference instance, not a universal distance table.

5. **Real package drawings take precedence over convenient library names.** V3 replaced a generic VSSOP footprint with TI's specified DGK land dimensions. A different UCC14141 land width was explicitly labeled a variant because it departs from the recommended footprint. Passing DRC cannot validate solder fillets, stencil design, placement tolerance or assembly yield. Record the drawing/revision, actual lead range, pad geometry and qualification gap. Never describe a modified land as an unchanged manufacturer recommendation.

6. **Distinguish source reference from supply ratiometry.** For [LEM HO 50–250-S](https://www.lem.com/sites/default/files/products_datasheets/ho-50__250-s_v7.pdf), use the specified reference/output law and account for reference output impedance. Buffer the reference if the downstream difference network would load it. Check offset/gain/temperature error, ADC clipping, cable-open behavior and absolute input voltages. Bidirectional sensing does not establish regenerative converter capability.

7. **Use the actual operating mode of an isolated midpoint supply.** Gate charge, asymmetric driver load, divider load, effective ceramic capacitance and hot internal regulator resistance all matter. A dual-positive sense supply is not the same load as a positive/negative gate supply. Retain source/sink and startup margin separately; a typical internal resistance is not a guaranteed bound. See [UCC14141-Q1](https://www.ti.com/lit/ds/symlink/ucc14141-q1.pdf) and [UCC21710-Q1](https://www.ti.com/lit/ds/symlink/ucc21710-q1.pdf).

8. **Split numerical evidence by what it establishes.** Averaged control execution can establish the implemented PI/quantization/delay model; event-aligned switching can resolve ripple; simple RC DESAT and Miller sweeps establish conditional circuit behavior. None validates semiconductor short-circuit survival or actual firmware latency. Store the unsafe counterexample as well as the accepted scenario. Target build evidence and oscilloscope timing remain separate requirements.

9. **Model a thermal interface as an assembly.** Datasheet ceramic conductivity/withstand and a heatsink curve do not give an assembled junction temperature or electrical qualification. Include live tab/contact area, spreader resistance, grease/contact layers, clamp pressure, flatness, edge creepage, PE fasteners and airflow impedance. An approximate STEP envelope is an interference-screening aid; it is not vendor mating geometry. The V3 copper-block/AlN fixture retains these items as open qualifications.

10. **Use native connectivity to repair routing.** A router's successful endpoint search does not establish complete net connectivity after zone filling. `native_route_repair.py` starts with actual native DRC opens and connected-component anchors; proposals still require refill, parity and all-severity native DRC. Dangling tracks/vias remain findings until removed or connected. Check the stored fills as delivered, not just a freshly computed transient result.

11. **Include plane area in projected insulation exclusions.** Excluding only pads and tracks can still leave hazardous copper under empty accessible-ground plane area on another layer. Reserve dedicated power corridors against actual accessible conductors, form complete accessible planes, then exclude their full projected area from hazardous pours. Re-export native filled copper and independently measure the projection. V3 caught this defect despite zero same-layer DRC violations; its final minimum is prototype-specific, not a general insulation rule.

12. **Screen current concentration, not only total plane area.** The multilayer DC mesh exposed one dominant low-side return via; added parallel transitions reduced its modeled branch fraction. Use real polygons with holes, a refinement comparison and explicit contact/plating/temperature assumptions. Solid-land simplifications, ideal contacts and missing AC/thermal coupling prevent treating the result as an ampacity or temperature-rise certificate. The reusable `sheet_resistance.py` retains these limitations in its output.

13. **Normalize native junctions before pruning dangling tails.** A long track can connect a valid branch in its middle while one end dangles. Deleting the entire reported segment removes that branch. Split at actual intersections/annulus contacts, retain anchored copper, remove exact duplicates, rerun native DRC and normalize again as needed. Never prune a whole net based on a stale report or assume a large bounding-box overlap proves a physical clearance violation.

14. **Validate the final export framing and source hashes.** Native PDF success does not mean that every layer is centered or clear of a title block. Inspect every page, front/back assembly view and tall-body 3D render; keep model approximations visible. Hash the complete hierarchical inputs and artifacts, and distinguish failed/obsolete run history from the latest checks used for the release review. Mechanical-model substitutions must be declared even when copper is unchanged.

The existing layout, isolated-bias, sensing and thermal knowledge records link these lessons as verification extensions. Current prototype-specific distances, temperatures and component values remain in `examples/sic-buck-400v-200v-5kw-v3/`; they are not promoted to universal or hardware-validated rules.
